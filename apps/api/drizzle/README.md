# Migrations

Generated by drizzle-kit (`meta/_journal.json` lists the files in order).

Keep the `"public".` schema prefix on every table name in the `.sql` files. The test harness `createTestApp` (and
`applyMigrations`) rewrites `"public".` to the per-test schema (`test_api_<hex>`) before running each statement, so a
table written without the prefix would be created in whatever schema the connection defaults to and escape the isolation.

The rewrite lives in `applyMigrations` in `apps/api/test/support/test-app.ts`:
`text.replaceAll('"public".', `"${schema}".`)`.
