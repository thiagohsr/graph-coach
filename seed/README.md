# Seed content

Everything in this folder is synthetic. It was written for this project (Graph Coach) and does not copy or adapt any third-party text, question bank, or dataset.

- Licence: released under the same licence as this repository.
- Demo users in `users.json` use addresses in the reserved `.test` domain (`example.test`). These addresses cannot receive mail and cannot belong to a real person. No password, username, or Cognito identifier appears in any seed file.
- `concepts.json`: the 25 concepts of the "Databases 101" tree and their prerequisites.
- `puzzles/`: six published, public puzzles (36 questions) owned by the demo admin.
- `sources/`: three original texts used as input for the Curator demo and tests, listed in `sources/index.json`. They are files only; the seed does not ingest them.
- `scenario.json`: the demo learner's history (weak-prerequisite scenario).
