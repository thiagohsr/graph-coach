# Recorded model responses

Used by the stub provider when `LLM_PROVIDER=stub` and `LLM_BASE_URL=file://<absolute path of this folder>`
(`StubChatProvider.fromRecordings(dir)` in `packages/agents/src/llm/stub.ts`). No model is called.

One file per call-site label: `<label>.json`, for example `curator.extractConcepts.json`.

```json
{
  "responses": [
    { "promptHash": "<sha-256 hex>", "response": { "any": "json" } },
    { "promptHash": "<sha-256 hex>", "response": "or a plain string" }
  ]
}
```

- `promptHash` is the sha-256 (hex) of the message contents joined with `"\n"` (roles are not hashed). Compute it with `promptHash(messages)` exported from `@coach/agents/llm`.
- An object or array `response` is returned as its JSON text; a string is returned as is.
- A call whose label or hash has no entry fails with `ProviderUnavailableError` naming the label and hash, never the prompt text.
- Only `.json` files directly inside the folder are read; labels must match `[A-Za-z0-9][A-Za-z0-9._-]*` and may not contain `..`.
- The folder is read once at start-up. Usage numbers stay deterministic (`stubTokens`).

This folder holds no recordings yet: they must be generated by running the real prompt builders, not written by hand.
